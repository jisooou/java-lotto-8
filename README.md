# **3주차 로또**

---

🧪: 테스트 케이스 

## **🔖 Model**

### **1. LottoNumber**

- 로또 번호 : 1~45

  🧪로또 번호는 범위가 1~45이어야 한다.


### **2. Lotto**

- 6개의 숫자로 이루어져 있다.

  🧪로또 번호는 6개여야 한다.

- 1장 가격은 1000원이다.

### **3. BonusNumber**

- 사용자로부터 입력받는 1개의 숫자이다.

  🧪보너스 번호는 1개여야 한다.


### **4. LottoResult**

- 로또 번호와 사용자로부터 입력받은 번호를 비교하여
    - 3~6개 일치 여부를 확인한다.
    - 각 일치하는 로또가 몇 개인지 확인한다.
    - 수익률을 계산한다.

---

## **🖥️ View**

### **InputView**

- 구입 금액을 입력받는다.   
  🧪구입 금액이 음수이면 안된다.  
  🧪구입 금액이 문자열이면 안된다. (예: “9000원”까지 입력)
- 당첨 번호 6개를 입력받는다.

  🧪당첨 번호가 1~45가 아닌 경우에는 재입력을 받는다.

- 보너스 번호 1개를 입력받는다.  
  🧪보너스 번호도 1~45가 아닌 경우에는 재입력을 받는다.

### **OutputView**

- 발행한 로또 수량을 출력한다.
- 발행한 로또 번호를 출력한다.
    - 로또 번호는 오름차순으로 출력한다.
- 당첨 내역을 출력한다.
- 수익률을 출력한다.
    - 소수점 둘째 자리에서 반올림한다.

### **LottoController**

- 사용자가 입력한 로또 구입 금액이 로또 금액인 1000원과 나누어 떨어지지 않는 경우  
  🧪 나누어 떨어지지 않으면, 예외 처리
